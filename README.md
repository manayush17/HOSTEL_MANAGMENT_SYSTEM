# 🏠 Hostel Management System

A web-based Hostel Management System built using **Django**. It allows students to check into available hostel rooms and enables admins to manage bookings, rooms, and users with ease.

---

## 🚀 Features

### 👩‍🎓 For Students:
- View available rooms
- Check in to a room (up to 3 students per room)
- Provide payment transaction ID for booking confirmation
- View current room allocation

### 👨‍💼 For Admins:
- View all room allocations
- Check currently available and booked rooms
- View booking records of all students

---

## ⚙️ Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML5, CSS3 (Custom styling)
- **Database**: SQL
- **Authentication**: Django’s built-in user model
